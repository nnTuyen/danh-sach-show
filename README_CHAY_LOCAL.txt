HUONG DAN MO NHANH

1. Bam dup vao file:
   Mo nhanh trang show.bat

2. Tool se tu dong:
   - Chay local server tai http://127.0.0.1:8000
   - Mo trang index.html bang trinh duyet
   - Neu server dang chay roi thi chi mo trang, khong tao them server trung

3. Neu bi loi:
   - Kiem tra may da cai Python chua
   - Hoac chay thu lenh sau trong thu muc nay:
     python -m http.server 8000 --bind 127.0.0.1

4. Khi sua show tren giao dien:
   - Bam Cai dat chung
   - Mo khoa
   - Sua va bam Luu show nay
   - Bam Tai showsData.json
   - Dung file JSON moi de thay showsData.json tren GitHub
