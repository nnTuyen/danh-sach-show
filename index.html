Sau khi bạn thêm show mới, sửa thông tin hoặc thay đổi show ghim, bấm nút bên dưới để tải file showsData.json mới. Dùng file vừa tải này để thay thế file showsData.json trong thư mục hoặc đẩy lên GitHub/Vercel.
